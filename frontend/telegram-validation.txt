  hidden while editing a task; the editor keeps its local draft state.

  Start, then confirms the displayed name, optional username and Telegram ID

  from enabled tasks will be shared there. Names and usernames use

  that button opens the Tasks view and focuses its navigation button.

  into Connection details, collapsed by default and keyboard-accessible.
  Confirmation is announced without repeating a visible success block.

  worker-offline and retryable error states. Status refreshes every three
  seconds after a request completes, pausing during a settings action.

  enabling Send matches to Telegram requires a linked account. Its helper
  explains how to link, and task rows show Telegram on when opted in.
- Linked settings show queued delivery counts and a delivery issue when
  present. Disconnect and /stop turn Telegram off for the account's tasks;
  the UI explains that a message already being sent may still arrive.
