Recurring-task sidebar validation (2026-11-15)

Scope
Recurring tasks have their own left-sidebar section between Pinned and Recents.
The heading opens task management; each task row opens its chat. Task chats are
excluded from ordinary groups even when pinned. Queued/running checks show a
rotating repeat arrow, including while a different chat is selected. Paused and
failed states have explicit labels. Failed refreshes expose Retry tasks and mark
the last status unavailable. Search includes tasks outside the returned chat list.
The client restores scheduled runs through task history because the ordinary
chat latest-run endpoint intentionally excludes them. A newer manual conversation
run takes precedence, and a new scheduled run updates an already-open task chat.

Direction
Scoped extension of Guuey's existing compact dark sidebar, system font, neutral
palette and native controls. ENERGY 1 / RHYTHM 1 / MOTION 1. Motion indicates actual
queued/running work; reduced motion keeps the repeat arrow still. The chevron
identifies the task-management destination. No new visual world or image assets.
This local extension establishes no new global design-system rules.
